# Nguồn diagram

HTML là nguồn, SVG nhúng Markdown được xuất bằng helper của [diagram-design](https://github.com/cathrynlavery/diagram-design/tree/550fd66edff058bc73056c3416b76d69cfe865ba), commit `550fd66edff058bc73056c3416b76d69cfe865ba`, giấy phép MIT, style mặc định được chọn trong yêu cầu. Giữ title/desc truy cập được, đường nối trực giao và không dùng screenshot làm nguồn.

Bốn figure: architecture, chat-sequence, corpus-lifecycle, deploy-recovery. Chỉnh HTML rồi dùng `skills/diagram-design/scripts/export_svg.py` tại commit trên để xuất lại SVG.
